# 🌦️ Advanced Weather App

A Python-based GUI Weather Application built using Tkinter and the OpenWeatherMap API.

## 📌 Project Overview

This application allows users to search for weather information by entering a city name. It retrieves real-time weather data from OpenWeatherMap and displays it in an easy-to-use graphical interface.

## ✨ Features

- Search weather by city name
- Current temperature
- Celsius and Fahrenheit unit toggle
- Humidity percentage
- Weather condition description
- Wind speed
- Weather condition icon
- Next 6 hours forecast
- 5-day forecast
- Empty input validation
- City-not-found error handling
- Invalid API key handling
- Network timeout and connection error handling
- GUI-based error messages

## 🛠️ Technologies Used

- Python
- Tkinter
- Requests
- JSON
- Pillow
- python-dotenv
- OpenWeatherMap API
