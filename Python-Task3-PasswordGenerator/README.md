# Random Password Generator

## Oasis Infobyte - Python Programming Internship

This project is a Random Password Generator developed as part of my Python Programming Internship at Oasis Infobyte.

## Project Description

This program generates random passwords based on the length and character types selected by the user.

The user can choose from:

- Uppercase letters (A-Z)
- Lowercase letters (a-z)
- Numbers (0-9)
- Symbols (!, @, #, $, etc.)

At least two character types must be selected to generate a password.

## Features

- User enters the required password length.
- Password length must be at least 8 characters.
- User can select different character types.
- At least two character types are required.
- The generated password includes at least one character from every selected type.
- Invalid inputs are handled properly.
- User can generate another password without restarting the program.

## Technologies Used

- Python
- Random module
- String module
