# Password Generator

## Description

This project is a simple Python password generator that creates a random password based on the length entered by the user.

## Features

- Generates random passwords
- Allows the user to choose the password length
- Uses letters, numbers, and special characters
- Requires a minimum password length of 8 characters
- Handles invalid input using error handling

## Technology Used

- Python

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run the following command:

   python password_generator.py

4. Enter the desired password length.

## Example

Enter password length: 12

Generated Password: A7@kP2!xQ9#m
